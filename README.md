# User Management System

## Project Description
The User Management System is a web-based application developed using Java Spring Boot, MySQL, HTML, CSS, and JavaScript.

It allows users to add, view, update, and delete user details.

## Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- HTML
- CSS
- JavaScript
- Maven

## Features
- Add New User
- View All Users
- Update User Details
- Delete User
- MySQL Database Connectivity

## Database
Database Name: `user_management`

Table Name: `users`

Fields:
- id
- name
- email
- phone

## How to Run
1. Configure MySQL database.
2. Update database credentials in `application.properties`.
3. Open the project folder in VS Code.
4. Run the command:

`mvnw.cmd spring-boot:run`

5. Open `http://localhost:8080` in your browser.
